后半场往往 **比八股更决定 offer**：项目真实性、角色、协作、学习力。本篇整理 SHEIN/富途/CVTE 常问的 **开放题与项目题** 答法。

***

### 一、项目介绍模板（2 分钟）

```text
1. 业务背景（谁用、解决啥）
2. 技术栈与架构图（一句话）
3. 我负责：模块 A、性能方案 B、基建 C
4. 难点：具体矛盾 + 我的决策
5. 结果：指标（延迟 -30%、崩溃率、交付周期）
```

避免「我们用了 vue element webpack」流水账。

***

### 二、高频项目追问

| 问题 | 答法要点 |
|------|----------|
| 最有亮点的项目 | 选 **可量化** 的一个，不要最老的 |
| 最大挑战 | 技术 + 协作各准备一个 |
| 内嵌 H5 做了哪些优化 | 离线包/懒加载/Bridge 减少跳转/监控 |
| 错误怎么上报 | Sentry + sourceMap + release + userId 哈希 |
| 性能监控平台 | FCP/LCP、API 耗时、白屏率、采样率 |
| 团队分工与你的角色 | 诚实：主 R / 协作 / 基建 —— 对齐 JD |
| 如何快速融入 | 文档、结对、先小 PR、对齐规范 |

***

### 三、性能监控（富途深挖）

上报字段示例：

* **性能**：FCP、LCP、CLS、长任务、资源慢请求
* **错误**：JS stack、component、route、release
* **业务**：traceId、tenantId（脱敏）

与 [Sentry 接入文](/2026/05/23/frontend-error-monitoring-sentry-reporting/) 一致即可。

***

### 四、算法题（面经出现）

* 排序找第 K 大 → 快排 partition 或堆
* 最长子序列 → DP
* 二叉树 → 递归/层序，说 **思路 + 复杂度** 即可

前端岗 **很少 hard 算法**；说不清可聊 **工程权衡**，别硬编。

***

### 五、开放题

**怎么学习？**

* 官方文档 + 做小项目验证
* 本站式 **错题本博客**
* 跟 AI 协作时 **仍跑测试验收**（见 AI 职业文）

**职业规划？**

* 1–3 年：深主栈 + 交付闭环
* 3–5 年：T 型 / 基建 / 带人（选真实方向）

**离职原因？**

* 客观：业务调整、技术栈不匹配、寻求 **更大职责**
* 忌：贬前雇主

**对下一份工作的期待？**

* 与 JD 对齐：技术栈、业务域、团队规模

***

### 六、互相了解环节

准备 **3 个问题** 问面试官：

* 团队前端分工与发布节奏？
* 三个月内期望产出？
* 技术债与质量闸？

***

### 七、小结

软技能题 **真诚 + 结构 + 与 JD 对齐**。八股专题见 [面经导读](/2026/05/25/interview-guide-index/)。
