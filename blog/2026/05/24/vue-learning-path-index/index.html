Vue导读红宝书整理

2026-05-23

01-前端核心 里既有 js-learn 红宝书笔记，也有 Vue2 源码，还有 Vue3 工程化 新文。本篇帮你 按目标选读，避免在源码里迷路或重复读同一知识点。

一、三条线

A. JavaScript 基础 ──► js-learn / ES6 系列
B. Vue 原理       ──► vue-learn-* + Vue 3 Proxy/编译
C. Vue 3 工程     ──► composition / pinia / router / TS
D. 通用前端       ──► CSS 布局 / i18n·a11y（栈无关）

可以 A → C 并行；B 适合想搞懂响应式时按需翻；D 作查漏补缺。

二、路径 A：JavaScript（面试 + 日常）

阶段推荐
语法基础js-learn 系列、ES6 模块/Promise 四篇
异步promise、paralle-request
DOM/BOMjs-learn-DOM、js-learn-event

标签：红宝书整理

三、路径 B：Vue 2 源码（理解用）

顺序建议：init → Dep/响应式 → render → mounted → build

  • vue-learn-init
  • defineProperty / Dep
  • render
  • mounted

不必 全背；读完 Dep 后建议接 Vue 3 响应式与编译运行时，再读 编译器 parse/transform/codegen，把 Proxy 与 patchFlag 对齐。迁移差异见 Vue2→3 迁移清单。

四、路径 C：Vue 3 工程（工作直接用）

顺序文章

2组合式 API 模式
3Composables 深入
4Pinia
5Router 权限
6TypeScript 配置 + Vue+TS
7Vitest 测试

五、路径 D：通用前端（查漏补缺）

主题文章
CSS 布局Flex 与 Grid 实战
国际化与无障碍i18n 工程化与 a11y 清单
GraphQL 接入Apollo Client 与缓存
PWAService Worker 与离线缓存（在工程化目录）

六、与全站其他目录的衔接

  • 构建： 构建与工程化专题目录（含 Docker 部署）
  • 性能：性能优化标签
  • 微前端：微前端标签
  • 中后台架构：08-架构 下 RBAC + 动态表单 + 文件预览链路

七、React 读者

维护 React 子应用：React + Vite 结构 → Hooks 与状态管理。

八、小结

上班写 Vue 3 → 走路径 C；补 JS 底子 → 路径 A；** curiosity 驱动 → 路径 B 挑章读；布局/i18n/部署 → 路径 D**。
