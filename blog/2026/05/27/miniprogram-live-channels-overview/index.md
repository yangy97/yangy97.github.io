带货、活动页常要 **小程序 + 直播 / 视频号** 组合。能力随微信版本迭代快，本篇讲 **常见集成模式、类目与资质、前端要做什么**，具体 API 以 [官方文档](https://developers.weixin.qq.com/miniprogram/dev/framework/) 为准。

***

### 一、几种形态

| 形态 | 说明 |
|------|------|
| **小程序内直播组件** | 直播间挂在小程序页面（需类目与接口权限） |
| **视频号主页/直播** | 从小程序 `openChannelsUserProfile` 等跳转视频号 |
| **小店 / 组件带货** | 与电商、订单系统打通 |

\==先确认类目==：并非所有小程序都能开直播，**后台能力开关** 为准。

***

### 二、典型流程（概念）

```text
1. 开通直播 / 视频号相关能力（资质、类目）
2. 创建直播间（后台或 API）
3. 小程序页面引入 live-player / 直播组件 或 跳转视频号
4. 商品库与订单走自有或微信小店
5. 支付、售后仍回小程序订单页 / 客服
```

***

### 三、前端注意

* **基础库版本** 门槛；低版本 **降级提示**
* 直播页 **性能**：避免同页 heavy 动画 + 直播同屏
* 分享路径带 **scene**，进房统计用 [生命周期](/2026/05/24/miniprogram-lifecycle-routing-navigation/) 解析
* 网络：**弱网重连**、封面图 CDN

***

### 四、与订单/支付

* 直播间下单 often 跳 **小程序订单页** 或 **半屏小程序**
* 支付走 [微信支付链路](/2026/05/17/miniprogram-payment-flow-and-reconciliation/)
* 库存与价格 **服务端校验**，不要只信前端传参

***

### 五、合规

* 直播内容、商品类目 **证照**
* 用户隐私（评论、中奖手机号）走 [隐私合规](/2026/05/26/miniprogram-privacy-compliance-guide/)
* 抽奖活动 **规则公示**

***

### 六、排障

| 现象 | 方向 |
|------|------|
| 组件不显示 | 类目、权限、基础库 |
| 黑屏 | 流地址、HTTPS、真机 |
| 无法跳转视频号 | appId 关联、用户是否安装微信 |

***

### 七、小结

直播/视频号 = **资质 + 官方组件/跳转 + 订单支付闭环**。细节随平台更新快，实施前 **先读当期开放文档** 再写代码。
